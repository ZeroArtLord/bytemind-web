# ByteMind Solutions — Next Generation V1.2

Web oficial de ByteMind Solutions, versión Next Generation V1.2, con red azul neón animada en toda la página.

## Publicación en GitHub Pages

1. Abre https://github.com/ZeroArtLord/bytemind-web/settings/pages
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige **main** y **/(root)**, luego **Save**.
4. Cuando aparezca la confirmación del despliegue, entra a https://zeroartlord.github.io/bytemind-web/

La web funciona como un HTML estático independiente: no requiere build, Node.js, npm ni secretos.

Las transmisiones de red y las ventanas de código son efectos visuales. El formulario de contacto prepara mensajes para WhatsApp o correo.
